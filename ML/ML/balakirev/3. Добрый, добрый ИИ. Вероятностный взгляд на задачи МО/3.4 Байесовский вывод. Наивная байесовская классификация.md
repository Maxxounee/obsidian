[Байесовский классификатор, отношение правдоподобия](https://www.youtube.com/watch?v=OhIp6qJkvCI)


$$
\begin{align}
&\frac{\omega(\bar{y}|H_{1})}{\omega(\bar{y}|H_{0})} \geq \frac{p_{0}R_{0}}{p_{1}R_{1}}
\text{ — отношение правдоподобия} \\ \\

&\text{Краткая запись: }\Lambda \geq \Lambda_{0}   \\
&\Lambda_{0} \text{ — Порог} \\ \\
&\Lambda \geq \Lambda_{0} \to H_{1} \text{ (гипотеза 2)}\\
&\Lambda < \Lambda_{0} \to H_{0} \text{ (гипотеза 1)}\\
\end{align}
$$

##### Пример:

$$
\begin{align} \\
&\text{Отношение правдоподобия:} \\  \\
&\ln \Lambda=\frac{1}{2\sigma^{2}_{1}}\cdot\left((y_{1}-m_{1}^{Ж})^{2} - (y_{1}-m_{1}^{М})^{2}\right)  \\
\\
&\sigma\text{ — Дисперсия разброса} \\
&m_{1}^{М} \ m_{1}^{Ж} \text{ — Среднее значение} \\
&y_{1} \text{ — Рассматриваемое значение} \\  \\ \\
&\text{Порог:} \\ 
& \ln \Lambda_{0} = \ln \frac{p_{0}}{p_{1}}=\ln \frac{0.48}{0.52}\approx-0.08  \\
 \\

&p_{0} \ \ p_{1}\text{ — Априорные вероятности} \\  \\
\end{align}
$$

```python
import numpy as np

# Отношение правдоподобия
def getL(y1, m1_F, m1_M, d1):
    res = 1/(2*d1)*((y1-m1_F)**2 - (y1-m1_M)**2)
    return res

# Порог
def getL0(p0, p1):
    return np.log(p0/p1)

m1_F = 60   # средний вес женщин (кг)
m1_M = 85   # средний вес мужчин (кг)

d1 = 9     # дисперсия разброса веса (кг^2)

p0 = 0.48   # вероятность для женщин
p1 = 0.52   # вероятность для мужчин

N = 100     # число экспериментов

L0 = getL0(p0, p1)

nM = 0
for i in range(N):
    y1 = np.random.normal(m1_F, d1)

    L = getL(y1, m1_F, m1_M, d1)

    if(L >= L0):
        print("Мужчина", y1)
        nM += 1
    else:
        print("Женщина", y1)

error = nM/N*100
print(f"Ошибка: {np.round(error, 2)}%")
```
