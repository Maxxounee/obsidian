Массивы в php оптимизированы для работы со всеми основными структурами данных.

**Структура данных** — это специализированный формат для организации, обработки и хранения данных в памяти компьютера.

Он обеспечивает эффективный доступ к данным и манипулирование ими, позволяя программистам более эффективно выполнять конкретные задачи.

Массив — это самая простая и широко используемая структура данных. Другие структуры данных, такие как стеки и очереди, являются производными от массивов.

С массивами в php можно делать практически всё, что угодно. Поэтому рекомендуется применять более жёсткие структуры данных под конкретные задачи, чтобы у программистов было меньше шансов ошибиться. Например, если нам нужны только уникальные элементы, лучше использовать множество, иначе программист в будущем сможет повторно добавить в массив элементы, что приведёт к потере уникальности элементов и возможным ошибкам. Поэтому мы создаём класс, в котором работаем с массивом, но ограничиваем возможные действия с этим массивом.

### Множество set

Это структура данных, в которой все элементы уникальны. Создать такую структуру очень просто - для этого нужно работать только с ключами массива, а значения игнорировать (например, делать все значения null или 0).

```php
class Set {
	private $data;

	public __construct($array) {
		foreach($array as $key => $value) {
			$this->data[$value] = null;  
			// Если значение во входном массиве повторится, ключ 
			// результирующего перезапишется
	    }
	}

	public function add($value) {
		$this->data[$value] = null;    
	}
	
	public function delete($value) {
		unset $this->data[$value];
	}
	
	public function getData() {
		return array_keys($this->data);
	}
}
```

Теперь если программист попробует создать множество с повторяющимися элементами или добавить в него элемент, который уже есть, ничего страшного не произойдёт.

Подобно стекам, очередь — хранит элемент последовательным образом. Существенное отличие от стека – использование FIFO (First in First Out) вместо LIFO.  
  
Пример очереди – очередь людей. Последний занял последним и будешь, а первый первым ее и покинет.

### Связанный список

Связанный список – массив где каждый элемент является отдельным объектом и состоит из двух элементов – данных и ссылки на следующий узел.  
  
Принципиальным преимуществом перед массивом является структурная гибкость: порядок элементов связного списка может не совпадать с порядком расположения элементов данных в памяти компьютера, а порядок обхода списка всегда явно задаётся его внутренними связями.  

* **Однонаправленный**, каждый узел хранит адрес или ссылку на следующий узел в списке и последний узел имеет следующий адрес или ссылку как NULL.  
	`1->2->3->4->NULL`

* **Двунаправленный**, две ссылки, связанные с каждым узлом, одним из опорных пунктов на следующий узел и один к предыдущему узлу.  
	`NULL<-1<->2<->3->NULL`
	  
* **Круговой**, все узлы соединяются, образуя круг. В конце нет NULL. Циклический связанный список может быть одно-или двукратным циклическим связанным списком.  
	`1->2->3->1`

Самое частое, линейный однонаправленный список. Пример – файловая система.

По сравнению с множеством, здесь в качестве объекта данных $data будет выступать двухмерный массив, значениями которого будут массивы из значения и указателя - индекса того элемента, с которым связывается данный. Так можно связывать не только числовые, но и ассоциативные массивы.

Рассмотрим пример кругового списка из жизни. У нас есть электрооборудование, которое последовательно соединено кабелем. В конструкторе схема будет создаваться только с источником питания, а потом заполняться:

![[PHP/__assets/img/3.05.png|center]]

```php
class ConnectionEquipment {
	$data = [
		'power' => [];
	];

	public __construct($powerType) {
		$data['power'] = [$powerType, null];
	}

	public function addEquipment($equipment) {
		$data[$equipment['index']] = [
			$equipment['type'], 
			$equipment['pointer']
		];
		$data['power']['pointer'] = $equipment['index']; 
		/* При добавлении каждого оборудования будем цеплять к нему указатель 
		второго конца источника питания */
	}

	public function deleteEquipment($index) {
		if ($index == 'power') { // Запрещаем удаление источника питания
			return;
		}
		
		$equipment = $data[$index];
		$newPointer = $equipment['pointer']; 
		/* Теперь нам нужно передать этот указатель
		оборудованию справа, чтобы цепь при удалении элемента 
		сохранилась замкнутой */
		
		foreach ($data as $item) {
			if ($item['pointer'] == $index) {
	
			$item['pointer'] = $newPointer(); 
			/* Присваиваем указатель оборудованию, которое 
			стоит на схеме справа от удаляемого, на то 
			оборудование, которое стоит слева от удаляемого */
			}
		}
		
		unset($equipment);
	}
}

$schema = new ConnectionEquipment('battery');
$schema->addEquipment('L1' => ['lamp', 'power']);
$schema->addEquipment('L2' => ['lamp', 'L1']);
$schema->addEquipment('L3' => ['lamp', 'L2']);
$schema->addEquipment('L4' => ['lamp', 'L3']);
$schema->addEquipment('L5' => ['lamp', 'L4']);
```

Мы взяли объект из реального мира - электрическую схему - и оцифровали его. Если усложнить класс: добавить в него координаты, массу, мощность и т.п. оборудования, создать методы для расчёта длины кабеля и т.д., мы получим систему автоматизированного проектирования электрических цепей. ```php
function createTree($arr) {
	$parents_arr = array();

	foreach($arr as $key=>$item) {
		$parents_arr[$item['parent_id']][$item['id']] = $item;
	}
	
	return $parents_arr;
}
```

Хотел бы заметить, что код еще не завершен – это только начало. Обратите внимание, что в качестве аргумента мы будем передавать массив из которого будет сформирована древовидная структура. Как Вы видите в коде, используя цикл foreach, мы обходим массив, переданный в виде аргумента, и формируем новый — $parents_arr, ключами которого, являются идентификаторы родительских категорий. И в каждой ячейке данного массива, содержится дополнительный подмассив – всех категорий (дочерних), у которых идентификатор родительской категории равен ключу соответствующего массива.

function createTree($arr) {

	$parents_arr = array();

	foreach(arr as $key=>$item) {
		$parents_arr[$item['parent_id']][$item['id']]=$item;
	}

	$treeElem = $parents_arr[0];

	generateElemTree($treeElem, $parents_arr);

	return $treeElem;
}
```

Обратите внимание, что мы создаем новый массив $treeElem, который далее возвращается как результат работы функции. И по умолчанию сохраняем в него элементы самого высокого уровня, которые содержатся в ключе с индексом 0, массива $parents_arr. По сути, сейчас мы получили массив элементов верхнего уровня, в который нужно добавить дочерние элементы, непосредственно в ячейку с ключом children. И сделает это дополнительная функция generateElemTree(), которую мы сейчас с Вами напишем.
