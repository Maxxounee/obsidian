Сортировка

```php
// Пузырьковая

$arr = [3, 4, 0, 6, 9, 1];  
$b = true;

while ($b == true) {    
	$b = false;     
	for ($i = 1; $i < count($arr); $i++) {
		if ($arr[$i] < $arr[$i - 1]) {
			$t = $arr[$i];
			$arr[$i] = $arr[$i - 1];
			$arr[$i - 1] = $t;
			$b = true;
		}   
	}  
} 
```
