
### Создание класса

```php
<?php

class Cat {
    public $name;
    public $age;
    
    public function __construct($name, $age) {
        $this->name = $name;
        $this->age = $age;
    }
}

$obj = new Cat(readline(), readline());
echo 'name: ' . $obj->name . PHP_EOL;
echo 'age: ' . $obj->age;
?>
```

### Error $e->getMessage()

Дана функция, которая выводит число на экран. Если функции передать 0, она выбрасывает исключение. Выведите на экран результат функции при штатном ответе, либо сообщение из исключения, если оно будет выброшено. Слово end должно быть выведено на отдельной линии, не зависимо от результата.

```php
function pr($n) {
	if ($n == 0) {
		throw new Exception('ex');
	}
	echo $n . PHP_EOL;
}

$n = 0;

try {
    pr($n);
} catch (Exception $e) {
	echo $e->getMessage() . PHP_EOL;
} finally {
    echo 'end';
}
```
