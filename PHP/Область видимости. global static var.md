### Статические переменные

Похожи на локальные переменные. Они отличаются тем, что после завершения работы функции их значение сохраняется. При каждом новом вызове функция использует ранее сохраненное значение. Например:

```php
`function $fun() {
  $a = 1;
  static $b = 1;
  $a++;
  $b++;
  echo $a . ' ';
  echo $b . PHP_EOL;
}

$fun; // 2 2
$fun; // 2 3
$fun; // 2 4
$fun; // 2 5

echo $a; //
echo $b; //
```

### Глобальные переменные

Глобальные переменные - это переменные, созданные в корне скрипта. Они по умолчанию не доступны внутри функции.

Чтобы обратиться внутри функции к глобальной переменной, необходимо использовать ключевое слово global или обратиться к элементу встроенного массива глобальных переменных скрипта `$GLOBALS` по ключу, соответствующему имени переменной без знака доллара:

```php
$a = 100;

function $fun() {
  echo $a; //
  echo global $a; // 100
  echo $GLOBALS['a']; // 100
}

echo $a; // 100

```
