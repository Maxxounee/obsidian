
* var_dump - выводит информацию о переменной

```php
$a = array(1, 2, array("a", "b", "c"));
var_dump($a);

/* array(3) {
  [0]=>
  int(1)
  [1]=>
  int(2)
  [2]=>
  array(3) {
    [0]=>
    string(1) "a"
    [1]=>
    string(1) "b"
    [2]=>
    string(1) "c"
  }
}
*/

$b = 3.1;
$c = true;
var_dump($b, $c);

/* 
float(3.1)
bool(true)
*/
```


eval. Вычисление строки

```php
echo eval("print 3 + 5;"); // без print не работает, потому что print внутри строки выполняется и сам выводит результат в вывод (буфер).

eval("echo 3 + 5;");

$result = eval("return 3 + 5;");
echo $result;  // выводит 8
```


switch case и break

```php
switch ($i) {
	case 0: echo "Значение переменной \$i равно 0";
	case 1: echo "Значение переменной \$i равно 1";
	case 2: echo "Значение переменной \$i равно 2";
}


/* PHP выполнит инструкцию echo каждого случая, если значение переменной $i равно 0! PHP выполнит инструкции echo двух последних случаев, если значение переменной $i равно 1. Код поведёт себя предсказуемо и выведет «Значение переменной $i равно 2», только если значение переменной $i равно 2. Поэтому лучше помнить об инструкциях `break`, даже если в конкретных обстоятельствах инструкции прерывания умышленно не указываются. */

```

### Null значение аргумента

Знак вопроса перед типом переменной означает, что параметр может принимать значение `null` в дополнение к указанному типу

```php
function foo(
	?string $a=null,  
	string|null $b='def' // альтернативный вариант
) {}
```
