Это ссылка на область памяти, в которой хранится переменная.

Обычно данные в PHP передаются по значению. Так происходит и при присваивании, и при передаче данных в функции.

```php
$a = 5;  
$b = $a;

$a = 4; 
echo $b; // 5
```

Если мы хотим сделать передачу по ссылке, то нужно использовать указатель `&`.

```php
$a = 5;  
$b = &$a; // Теперь $a и $b ссылаются на одни и те же данные`

$a = 4;   echo $b; // 4
```

Если возникла острая необходимость изменить значение глобальной переменной внутри функции, мы можем при создании функции добавить указатель к параметру:

```php
$a = 0;
$b = 0;

function $fun($aa, &$bb) {
  $aa++;
  $bb++;
}

$fun($a, $b);

echo $a; // 0
echo $b; // 1

$fun($a, $b);

echo $a; // 0
echo $b; // 2
```
