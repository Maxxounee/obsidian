
Вывести названия книг, которые ни разу не были заказаны, отсортировав в алфавитном порядке.

```sql
SELECT
    title AS "Книги 2020"
FROM
    book
    LEFT JOIN buy_book USING(book_id)
WHERE 
    buy_book.amount IS NULL

;



SELECT
    title AS "Книги 2019"
FROM
    book
    LEFT JOIN buy_archive USING(book_id)
WHERE
    buy_archive.amount IS NULL
```
