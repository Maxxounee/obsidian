[Composer](https://getcomposer.org/download/) — менеджер зависимостей (A dependency Manager for PHP). 

Создание проекта:

```bash
composer create-project laravel/laravel example_app
```

Проверка, что все установилось нормально:

```bash
cd example_app
php artisan
```
