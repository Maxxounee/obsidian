Soft delete отличается от обычного удаления строки из таблицы. Soft delete помечает строку датой в колонке `deleted_at`, сохраняя, но не выводя данные.

#### PostController
```php
 public function delete() {
        /*
        В модели использовать use SoftDeletes.
        При создании (и миграции) таблицы использовать
        $table->softDeletes();
        */
        $post = Post::find(6);
        if ($post) {
	        # При соблюдении условий soft delete, не удалит
	        # значение, а "скроет"
            $post->delete();
        }
        
		# Искать так же в удаленных.
		$post = Post::withTrashed()->find(7);
		if ($post) {
			# "Восстановить" строку. Удаляет значение в deleted_at
	        $post->restore();
		}
}
```
