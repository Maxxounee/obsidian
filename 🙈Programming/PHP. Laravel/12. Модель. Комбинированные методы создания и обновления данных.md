
## firstOrNew

Метод `firstOrNew` действительно полезен для поиска первой модели, соответствующей некоторым ограничениям, или для создания новой, если ни одна не соответствует этим ограничениям.

Вы можете взять код, который выглядит так:


```php
$user = User::where('email', request('email'))->first();

if ($user === null) {
	$user = new User(['email' => request('email')]);
} 

$user->name = request('name'); 
$user->save()
```

И превратить его в это:

```php
$user = User::firstOrNew(['email' =>  request('email')]); 
$user->name = request('name'); 
$user->save()
```

Вы также можете передать массив дополнительных атрибутов для установки в качестве второго параметра, если существующая модель не найдена:

```php
$user = User::firstOrNew(
    ['email' =>  request('email')],
    ['name' => request('name')]
);
 
$user->save();
```

## firstOrCreate

Метод `firstOrCreate` очень похож на метод `firstOrNew`. Он пытается найти модель, соответствующую атрибутам, которые вы передаёте в первом параметре. Если модель не найдена, он автоматически создаёт _и сохраняет_ новую модель после применения любых атрибутов, переданных во втором параметре:

```php
$user = User::firstOrCreate(
    ['email' =>  request('email')],
    ['name' => request('name')]
);
// No call to $user->save() needed
 ```



## firstOr

Я недавно обнаружил метод `firstOr`, изучая исходный код. Метод `firstOr` извлекает первую модель из запроса, а если соответствующая модель не найдена, он вызовет переданный callback. Это может быть действительно полезно, если вам нужно выполнить дополнительные действия при создании пользователя или сделать что-то другое, кроме создания нового пользователя:

```php
$user = User::where('email', request('email'))->firstOr(function () {
    $account = Account::create([ //... ]);
 
    return User::create([
        'account_id' => $account->id,
        'email' => request('email'),
    ]);
});
```

## updateOrCreate

Метод `updateOrCreate` пытается найти модель, соответствующую ограничениям, переданным в качестве первого параметра. Если соответствующая модель найдена, он обновит её атрибутами, переданными во втором параметре. Если соответствующая модель не найдена, будет создана новая модель с ограничениями, переданными в первом параметре, и атрибутами, переданными во втором параметре.

Вы можете отрефакторить этот код:

```php
$user = User::where('email', request('email'))->first();
 
if ($user !== null) {
    $user->update(['name' => request('name')]);
} else {
    $user = User::create([
      'email' => request('email'),
      'name' => request('name'),
    ]);
}
 
// Do other things with the User
```

В это, используя метод `updateOrCreate`:

```php
$user = User::updateOrCreate(
    ['email' =>  request('email')],
    ['name' => request('name')]
);
 
// Do other things with the User
```
