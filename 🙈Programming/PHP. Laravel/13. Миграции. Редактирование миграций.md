При `php artisan migrate:fresh` миграция очистит все данные из таблицы.
Для изменения миграции и сохранения данных создается новая миграция.

### Добавление колонки 

Добавим новую колонку:

```bash
php artisan make:migration add_column_description_to_posts_table

# add_column_description — конвенция разработчиков. Просто удобно для чтения и поиска

# to_posts_table — конвенция Laravel. Обязательный синтаксис, чтобы laravel это автоматически привязал к текущей модели Post
```

Обновляем add_column_description_to_posts_table.php

```php
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration {
    public function up(): void {
        Schema::table('posts', function (Blueprint $table) {
            /* Обязательно nullable, потому что в таблице уже
            есть записи
            */
            $table->text('description')->nullable();
        });
    }

    public function down(): void {
        Schema::table('posts', function (Blueprint $table) {
            /* Для миграций изменений всегда прописывать
            поведение для отката этой миграции*/
            $table->dropColumn('description');
        });
    }
};
```

Мигрируем:

```bash
php artisan migrate
```

Откатываем изменения (rollback откатывает на одну миграцию назад)

```bash
php artisan migrate:rollback
```

Добавляем новые изменения в миграцию:

```php
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration {
    public function up(): void {
        Schema::table('posts', function (Blueprint $table) {
            /* Обязательно nullable, потому что в таблице уже
            есть записи
            */
            $table
                ->text('description')
                ->nullable()
                ->after('content');
        });
    }

    public function down(): void {
        Schema::table('posts', function (Blueprint $table) {
            /* Для миграций изменений всегда прописывать
            поведение для отката этой миграции*/
            $table->dropColumn('description');
        });
    }
};
```

### Удаление колонки

Удаляем миграцию:

```bash
php artisan make:migration delete_column_description_to_posts_table
```

Обновили delete_column_description_to_posts_table.php

```php
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration {
    public function up(): void {
        Schema::table('posts', function (Blueprint $table) {
            /* Код для удаления колонки */
            $table->dropColumn('description');
        });
    }

    public function down(): void {
        Schema::table('posts', function (Blueprint $table) {
            /* Код для rollback. Просто скопировали из миграции add_column... */
            $table
                ->text('description')
                ->nullable()
                ->after('content');
        });
    }
};
```

### Изменение колонки

Создаем миграцию

```bash
php artisan make:migration edit_column_content_to_posts_table
```

Пишем код

```php
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration {
    public function up(): void {
        Schema::table('posts', function (Blueprint $table) {
            /* было text, стало string */
            $table->string('content')->change();
            /* переименовали */
            $table->renameColumn('content', 'post_content');
        });
    }

    public function down(): void {
        Schema::table('posts', function (Blueprint $table) {
            $table->renameColumn('post_content', 'content');
            $table->text('content')->change();
        });
    }
};
```

Мигрируем

```bash
php artisan migrate
```
