Создаем новый view в `resourses/views/`. Blade — интерпритатор для php. Позволяет использовать конструкции @foreach и тп.

```php
# posts.blade.php
<body>
<div>
	# $posts передаются через контроллер
    @foreach($posts as $post)
        <div>
            {{ $post->title }}
        </div>
    @endforeach
</div>
</body>
```

Контроллер PostController.php

```php
class PostController extends Controller {
    public static function index() {
	    # Получили инфу из БД
        $posts = Post::all();
        dump($posts);

		# Отдаем наш view (сам смотрит в /resourses/views)
		# и передаем переменную $posts через compact()
        return view(
            'posts',
            compact(['posts'])
        );
		# Или так можно
		return view(
            'posts',
            ['posts' => $posts]
        );
        }
}
```
