```bash
php artisan serve
```


### Router 

Директория роутера:

`./routes/web.php`

Содержимое:

```php
<?php  
  
use Illuminate\Support\Facades\Route;  
  
Route::get('/', function () {  
	return view('welcome');  
});
```

Добавить роут:

```php
Route::get('/example', function () {  
	return 'Hello world';  
});
```
