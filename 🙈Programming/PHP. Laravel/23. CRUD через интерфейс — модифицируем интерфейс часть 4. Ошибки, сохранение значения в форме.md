## Ошибки отправки формы и сохранение значения в полях

[The @error Directive](https://laravel.com/framework/docs/validation#the-at-error-directive)

#### views/Create.blade.php

##### Ошибка и сохранение поля при неудачной отправке

```vue
 <div class="mb-3">
            <label for="title" class="form-label">Title</label>
            <input
                value="{{ old('title') }}"
                name="title"
                type="text"
                class="form-control @error('title') is-invalid @enderror"
                id="title"
                placeholder="Ваш title..."
            >
            @error('title')
            <p class="text-danger">{{ $message }}</p>
            @enderror
        </div>
```

##### Сохранение поля

```vue
 <select
                name="category_id"
                class="form-select form-select-sm"
                id="category_id"
                aria-label=".form-select-sm example"
            >
                @foreach($categories as $category)
			<option
				value="{{ $category->id }}"
				{{ old('category_id') == $category->id  ? 'selected' : '' }}
>{{ $category->title }}</option>
                @endforeach
            </select>
```

```vue
@foreach($tags as $tag)
                <div class="form-check form-check-inline">
			<input
				name="tags[]"
				class="form-check-input"
				type="checkbox"
				id="inlineCheckbox{{$tag->id}}"
				value="{{ $tag->id }}"
				{{ in_array($tag->id, old('tags') ?? []) ? 'checked' : '' }}
                    >
                    <label class="form-check-label" for="inlineCheckbox{{$tag->id}}">
                        {{ $tag->title }}
                    </label>
                </div>
            @endforeach
```
