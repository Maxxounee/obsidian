Контроллеры:

`./app/http/controllers/Controller.php`

Создание нового контроллера:

```bash
# CamelCase. В конце пишем "Controller" (конвенциональновое)
php artisan make:controller MyPlaceController
```

```php
# ./app/http/Controllers/MyPlaceController.php
<?php  
  
namespace App\Http\Controllers;  
  
use Illuminate\Http\Request;  
  
class MyPlaceController extends Controller  
{  
	# Функцию прописали сами
	public function index() {  
		return 'this is my page';  
	}  
}
```

В модели создаем новый роут

```php
#./routes/web.php
<?php  
  
use Illuminate\Support\Facades\Route;  
  
Route::get('/', function () {  
	return view('welcome');  
});  

# Вторым параметром передаем путь до контроллера и @метод
Route::get(  
	'/my_page',  
	'App\Http\Controllers\MyPlaceController@index'  
);

# Или импортом
use App\Http\Controllers\MyPlaceController;

Route::get(  
	'/test',  
	[MyPlaceController::class, 'index']  
);
```
