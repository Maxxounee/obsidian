
## Метод find

Метод find хранится в Model, который наследуется от класса Builder 
(`vendor/laravel/framework/src/illuminate/database/eloquent/Builder.php`).

* В папку `vendor` laravel складывает все зависимости (и самого себя)
* Eloquent — (англ. красноречивый) ORM для работы с SQL

#### Контроллер PostController.php:

```php
public static function index() {
        $post = Post::find(1);
        ...
```

#### Builder.php

```php
  public function find($id, $columns = ['*'])
    {
        if (is_array($id) || $id instanceof Arrayable) {
            return $this->findMany($id, $columns);
        }

        return $this->whereKey($id)->first($columns);
    }```
