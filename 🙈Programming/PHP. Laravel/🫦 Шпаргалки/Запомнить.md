### Обращение к связным таблицам:

При реализации обращения к связным данным

```php
$post->tags # просто отдает связанные с post теги
$post->tags() # вызов сохраняет соедиенение и позволяет выполнять еще инструкции $post->tags()->esheInstruction();
```

```php
class Post extends Model {
    /* Один ко многим */
    /* Посмотреть данные из таблицы category по category_id = N */
    /* PostController.php:
        $post = Post::find(1);
        dd($post->category);
    */
    public function category() {
        return $this->belongsTo(
            Category::class,
            'category_id',
            'id'
        );
    }

    /* Многие ко многим */
    public function tags() {
        return $this->belongsToMany(
            Tag::class,
            'post_tags',
            'post_id',
            'tag_id',
        );
    }
}```
