Rabbitmq облегчает процесс передачи данных от одного сервиса к другому.

## Amqplib

Установим [php-amqplib](https://github.com/php-amqplib/php-amqplib)

```bash
composer create-project laravel/laravel rabbitmq/service_1
composer create-project laravel/laravel rabbitmq/service_2

cd service_1 # publisher
composer require php-amqplib/php-amqplib

cd service_2 # consumer
composer require php-amqplib/php-amqplib
```

## Get started

https://www.rabbitmq.com/tutorials/tutorial-one-php


Создадим команду в app/console/commands/ConsumeCommand.php

```bash
# service_1
php artisan make:command PublishCommand
```

```bash
# service_2
php artisan make:command ConsumeCommand
```

Далее все по документации:

```php
# service_1

#[Signature('app:publish-command')] // Вот эту штуку надо убрать, если используется свойство $signature (и импорт тоже)
#[Description('Command description')]
class PublishCommand extends Command
{
    protected $signature = 'rabbitmq:publish';
    
    public function handle()
    {
	    # Устанавливаем соединение с сервером rabbit
        $connection = new AMQPStreamConnection(
            'localhost', # host
            5672, #port
            'guest', #user
            'guest' #pass
        );

		# Открываем канал (постоянное соединение. Сокеты)
        $channel = $connection->channel();

		# Создаем очередь
        $channel->queue_declare(
            'hello', 
            false, 
            true, 
            false, 
            false, 
            false,
            new AMQPTable(['x-queue-type' => 'quorum'])
        );

		# Содаем сообщение
        $msg = new AMQPMessage('Hello World!');
        # Отправляем сообщение в очередь
        $channel->basic_publish($msg, '', 'hello');

        echo " [x] Sent 'Hello World!'\n";

		# В конце нужно все закрыть
        $channel->close();
        $connection->close();
    }
}
```

```php
#service_2

#[Signature('app:consume-command')] // Вот эту штуку надо убрать, если используется свойство $signature (и импорт тоже)
#[Description('Command description')]
class ConsumeCommand extends Command
{
    protected $signature = 'rabbitmq:consume';

        public function handle() {
        $connection = new AMQPStreamConnection(
            'localhost',
            5672,
            'guest',
            'guest'
        );
        
        $channel = $connection->channel();

        $channel->queue_declare(
            'hello',
            false,
            true,
            false,
            false,
            false,
            new AMQPTable(['x-queue-type' => 'quorum'])
        );

        echo " [*] Waiting for messages. To exit press CTRL+C\n";

        $callback = function (AMQPMessage $msg) {
            echo ' [x] Received ', $msg->getBody(), "\n";
        };

        $channel->basic_consume(
            'hello', 
            '',
            false,
            true,
            false,
            false,
            $callback
        );

        try {
            $channel->consume();
        } catch (\Throwable $exception) {
            echo $exception->getMessage();
        }
    }
}
```

Отправляем команду в очередь

```bash
php artisan rabbitmq:publish
```

Подписываемся на канал (соединяемся) и получаем сообщения

```bash
php artisan rabbitmq:consume
```
