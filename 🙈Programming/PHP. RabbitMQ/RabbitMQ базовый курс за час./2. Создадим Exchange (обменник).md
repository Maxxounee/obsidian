1. Вкладка `exchanges` -> `add a new exchange`

| Поле        | Значение | Описание                                                                                                                                                     |
| ----------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Name        | Laravel  |                                                                                                                                                              |
| Type        | Fanout   | Fanout отдает запрос во все очереди одновременно. Direct отдает по одному запросу в очередь поочередно                                                       |
| Durabillity | Durable  | Будет ли exchange жить после того, как rabbitmq перезапустится                                                                                               |
| Auto delete | No       | Удалить обменник после того, когда все очереди или обменники будут отвязаны от этого обменника                                                               |
| Internal    |          | Если "yes", то клиенты не смогут выполнять публикацию непосредственно в эту точку обмена. Ее можно использовать только в связках типа "exchange-to-exchange" |
| Arguments   | -        |                                                                                                                                                              |
