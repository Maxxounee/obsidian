## Установка

https://www.rabbitmq.com/docs/install-homebrew

```bash
brew install rabbitmq
brew info rabbitmq
brew services start rabbitmq
brew services stop rabbitmq

brew services list // проверка работы сервера
```

## Установлен в 

[/opt/homebrew/etc/rabbitmq/](file:/opt/homebrew/etc/rabbitmq/)
[/opt/homebrew/Cellar/rabbitmq](file:/opt/homebrew/Cellar/rabbitmq)

```bash
open /opt/homebrew/etc/rabbitmq/
open /opt/homebrew/Cellar/rabbitmq
```

## Включить плагин rabbitmq_management

rabbitmq_management — панель управления

```bash
cd /opt/homebrew/Cellar/rabbitmq/{version}/sbin

rabbitmq-plugins list
rabbitmq-plugins enable rabbitmq_management
```
