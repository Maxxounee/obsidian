Добавим контроллер:

```php
abstract class Controller {  
	public $app;  
   
	public function setApp() {  
		$this->app = FW::getApp();  
	}  
   
	public abstract function actionIndex();  
}
```

В контроллер мы добавили свойство $app и сеттер для него. Сеттер нужно будет вызывать в экшенах контроллеров, унаследованных от Controller. Например:

```php
class SiteController extends Controller {  
	public function actionIndex() {  
		parent::setApp();  
		return $this->app->getUrl();  
	}  
}
```

Экшен actionIndex() контроллера SiteController будет возвращать url. Так нужно будет делать экшены в задачах. 

Представление добавлять не будем, т.к. это - фронтенд. Вместо этого добавим в конструктор класса App получение данных из тестового ввода - это будет имитация запросов, которые прилетают с фронтенда.

```php
public function __construct() {
	$link = readline();
	$requestType = readline();
	$n = readline();
	$head = [];
	
	for ($i = 0; $i < $n; $i++) {
		$arr = explode(': ', readline());
		$head[$arr[0]] = $arr[1];
	}
	
	$body = readline();
	
	if (!self::validateUrl($link)) {
		$this->apiUrl = null;
		$this->urlParams = null;
		$this->requestType = null;
		$this->headers = null;
		$this->bodyParams = null;
	} else {
		$this->apiUrl = self::getApiUrl($link);
		$this->urlParams = self::getParams($link);
		$this->requestType = $requestType;
		$this->headers = $head;
		$this->bodyParams = $requestType == 'POST'
		? static::getBodyParams($body) 
		: null;
	}
}
```

Итак, в контроллере представлен абстрактный метод-экшен. Экшен - это метод контроллера, который вызывается путём перехода на урл. Например, у нас есть  домен: domain.com, контроллер  siteController (унаследованный от  Controller) и экшен actionIndex(). Чтобы запустить экшен, нужно перейти по урлу: http://domain.com/site/index. Реализовать это в нашем фреймворке очень сложно и не имеет смысла в данном курсе, поэтому экшены контроллеров в задачах будем вызывать в невидимом коде.

Итак, наш фреймворк будет иметь вид:

```php
<?php

class FW {
	public static function getApp() {
		return new App();
	}
}

class App {
	private $apiUrl;
	private $urlParams;
	private $requestType;
	private $headers;
	private $bodyParams;

	public function __construct() {
		$link = readline();
		$requestType = readline();
		$n = readline();
		$head = [];
		
		for ($i = 0; $i < $n; $i++) {
			$arr = explode(': ', readline());
			$head[$arr[0]] = $arr[1];
		}
		
		$body = readline();
		
		if (!self::validateUrl($link)) {
			$this->apiUrl = null;
			$this->urlParams = null;
			$this->requestType = null;
			$this->headers = null;
			$this->bodyParams = null;
		} else {
			$this->apiUrl = self::getApiUrl($link);
			$this->urlParams = self::getParams($link);
			$this->requestType = $requestType;
			$this->headers = $headers;
			$this->bodyParams = $requestType == 'POST'
			? static::getBodyParams($body) 
			: null;
		}
	}

	private static function validateUrl($link) {
		if (filter_var($link, FILTER_VALIDATE_URL) === false) {
			return false;
		}
		return true;
	}

	public function getUrl() {
		return $this->apiUrl;
	}

	public function getUrlParams() {
		return $this->urlParams;
	}

	public function getRequestType() {
		return $this->requestType;
	}

	public function getHeaders() {
		return $this->headers;
	}

	public function getPostParams() {
		return $this->bodyParams;
	}

	private static function getApiUrl($link) {
		$url = $link;
		$pos = strpos($url, '?');
		
		if ($pos === false) {
			return $url;
		}
		
		$url = substr($link, 0, $pos);
		
		return $url;
	}

	private static function getParams($link) {
		$pos = strpos($link, '?');
		
		if ($pos === false) {
			return null;
		}
		
		$queryString = substr($link, $pos + 1, strlen($link));
		$arr = explode('&', $queryString);
		$get = [];
		
		foreach ($arr as $item) {
			$temp = explode('=', $item);
			$get[$temp[0]] = $temp[1];
		}
		
		return $get;
	}

	private static function getBodyParams($body) {
		if (is_array($body)) {
			return $body;
		}
		
		try {
			$params = json_decode($body, true);
			return $params;
		} catch (Exception $e) {
			return null;
		}
	}
}

abstract class Controller {
	public $app;

	public function setApp() {
		$this->app = FW::getApp();
	}

	public abstract function actionIndex();
}

?>
```
