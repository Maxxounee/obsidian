
| Funcion....  | Description                                                                                                                                                                          |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| gettype()    | string; NULL; array; bool; int; string;...                                                                                                                                           |
| empty()      | true/false. Проверяет, считается ли переменная пустой. Переменная считается пустой, если она не существует или её значение равно false. Краткий эквивалент конструкции `!isset(var)` |
| is_null()    | true/false. Проверяет, равно ли значение переменной `null`                                                                                                                           |
| isset()      | Определена ли переменная значением, отличным от `null`                                                                                                                               |
| `(bool) var` | Приводит любое значение к типу bool. Выводит true/false. False: `false`; `0`; `0.0`; []; `NULL`;                                                                                     |
| is_numeric() | Число ли                                                                                                                                                                             |
| is_int()     | Int ли                                                                                                                                                                               |

`<>` — альтернативный вариант "не равно" (`!=`)
