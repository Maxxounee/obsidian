switch case и break

```php
switch ($i) {
	case 0: echo "Значение переменной \$i равно 0";
	case 1: echo "Значение переменной \$i равно 1";
	case 2: echo "Значение переменной \$i равно 2";
}


/* PHP выполнит инструкцию echo каждого случая, если значение переменной $i равно 0! PHP выполнит инструкции echo двух последних случаев, если значение переменной $i равно 1. Код поведёт себя предсказуемо и выведет «Значение переменной $i равно 2», только если значение переменной $i равно 2. Поэтому лучше помнить об инструкциях `break`, даже если в конкретных обстоятельствах инструкции прерывания умышленно не указываются. */

```

### \DateTime() что за синтаксис с косой чертой?

Это **глобальное пространство имен** (global namespace) в PHP. Обратная косая черта (`\`) указывает, что класс нужно искать в **корневом (глобальном) пространстве имен**, а не в текущем.

```php
namespace MyApp;
// Без \ - ищет в текущем пространстве имен
$date = new DateTime();  // Ищет класс MyApp\DateTime

// С \ - ищет в глобальном пространстве
$date = new \DateTime(); // Ищет класс \DateTime (встроенный)
```

```php
<?php
namespace MyApp;

// Создаем свой класс DateTime
class DateTime {
    public function __construct() {
        echo "Мой DateTime!";
    }
}

// Используем свой класс
$date1 = new DateTime();        // "Мой DateTime!"

// Используем глобальный (встроенный) DateTime
$date2 = new \DateTime();       // Объект \DateTime
$date3 = new \DateTime('now');  // Работает с встроенным классом
?>
```

## \$$var

Отличный вопрос! `$$name[$key]` - это **переменная переменная** с доступом по индексу.

Что такое переменная переменной?

**`$$name`** означает: "возьми значение переменной `$name` и используй его как ИМЯ другой переменной".

### Простой пример

```php
$name = "username";
$username = "John";

echo $$name;  // John
```

**Как это работает:**

1. `$name` = `"username"`
    
2. `$$name` = `$username`
    
3. `$username` = `"John"`
    
4. Вывод: `John`

Еще пример:

```php
$_GET = [
  'system' => 'astra',
  'version' => '2.0',
];
$_POST = [
  'user' => 'ivanov',
  'age' => 18,
];

$name = '_' . readline(); // _GET
$key = readline(); // version

echo $$name[$key]; // 2.0
```
