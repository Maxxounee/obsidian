## Задание

Заполнить таблицу `**author**`. В нее включить следующих авторов:

- Булгаков М.А.
- Достоевский Ф.М.
- Есенин С.А.
- Пастернак Б.Л.

```sql
INSERT INTO author
VALUES
    (DEFAULT, "Булгаков М.А."),
    (DEFAULT,"Достоевский Ф.М."),
    (DEFAULT,"Есенин С.А."),
    (DEFAULT,"Пастернак Б.Л.")
    
;

SELECT * FROM author
```
