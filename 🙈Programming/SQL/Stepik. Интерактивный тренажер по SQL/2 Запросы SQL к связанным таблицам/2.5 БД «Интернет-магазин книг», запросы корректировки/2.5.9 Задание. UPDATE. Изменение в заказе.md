Завершить этап «**Оплата**» для заказа с номером 5, вставив в столбец `**date_step_end**` дату 13.04.2020, и начать следующий этап («**Упаковка**»), задав в столбце `**date_step_beg**` для этого этапа ту же дату.

Реализовать два запроса для завершения этапа и начала следующего. Они должны быть записаны в общем виде, чтобы его можно было применять для любых этапов, изменив только текущий этап. Для примера пусть это будет этап «**Оплата**».

```sql
UPDATE
    buy_step
SET
    date_step_end = "2020-04-13"
WHERE
    step_id = (SELECT step_id FROM step WHERE name_step = "Оплата")
    AND buy_id = 5
;

UPDATE
    buy_step
SET
    date_step_beg = "2020-04-13"
WHERE
    step_id = (SELECT step_id FROM step WHERE name_step = "Упаковка")
    AND buy_id = 5
;



/* Вариант 2 */
UPDATE 
	buy_step AS BS, 
	buy_step AS BS1
SET
	BS.date_step_end = '2020-04-13',
	BS1.date_step_beg = '2020-04-13'
WHERE 
	BS.buy_id = 5 
	AND BS.step_id = 1 
	AND BS1.step_id = 2
;

/* Вариант 3 */

UPDATE 
	buy_step AS bs1,
	buy_step AS bs2
SET
	bs1.date_step_end = '2020-04-13',
    bs2.date_step_beg = '2020-04-13'
WHERE 
	bs1.buy_id = 5
	AND bs2.buy_id = bs1.buy_id
	AND bs1.step_id = (SELECT step_id FROM step WHERE name_step = 'Оплата')
	AND bs2.step_id = bs1.step_id + 1;

SELECT * FROM buy_step
WHERE buy_id = 5;

/* С переменными */

-- номер заказа для перевода в следующее состояние
SET @buy_id_to_change = 5;
-- "текущая дата" для перевода заказа в следующее состояние
SET @cur_date = "2020.04.13";

-- отобразим таблицу шагов до внесения изменений
SELECT * FROM buy_step WHERE buy_id = @buy_id_to_change;

-- определим номер текущего шага (step_id) заказа
SET @current_step_id = 
(
    SELECT MIN(step_id)
    FROM   buy_step WHERE buy_id = @buy_id_to_change AND date_step_end IS NULL
);

-- завершим текущий шаг
UPDATE buy_step
SET    date_step_end = @cur_date
WHERE  buy_id = @buy_id_to_change AND step_id = @current_step_id;

-- начнем следующий шаг
UPDATE buy_step
SET    date_step_beg = @cur_date
WHERE  buy_id = @buy_id_to_change AND step_id = @current_step_id + 1;

-- отобразим таблицу шагов после внесения изменений
SELECT * FROM buy_step WHERE buy_id = @buy_id_to_change;
```
