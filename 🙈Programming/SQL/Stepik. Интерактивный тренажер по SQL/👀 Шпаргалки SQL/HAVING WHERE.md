**WHERE** выполняется до формирования групп **GROUP BY**. HAVING — после

В **HAVING** и только в нём можно писать условия по агрегатным функциям (SUM, COUNT, MAX, MIN и т. д.). То есть если вы хотите сделать что-то вроде COUNT(_) > 10, то это возможно сделать только в_ _HAVING_*.

`WHERE` фильтрует данные _перед_ тем, как ты их агрегируешь. `HAVING` фильтрует по результатам агрегирования.
