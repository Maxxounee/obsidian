### DATEDIFF

```sql
DATEDIFF('2020-04-01', '2020-03-28')=4

DATEDIFF('2020-05-09','2020-05-01')=8

DATEDIFF(date_last, date_first)
```

### MONTH()

```sql
MONTH('2020-04-12') = 4
```

### MONTHNAME

```sql
MONTHNAME('2020-04-12')='April'
```


### YEAR()

```sql
YEAR('2020-04-12') = 2020
```

### DATE_ADD

```sql
SELECT
    name_city,
    name_author,
    DATE_ADD("2020-01-01", INTERVAL FLOOR(RAND() * 365) DAY) AS Дата
```
