### Omit, Pick

```ts
interface User {  
    id: string;  
    username?: string;  
    age: number;  
    birthday: {  
        year: number;  
        day: number;  
        month: number;  
    }  
}  
  
type PropsToOmit = 'id' | 'age';  
type NewUser = Omit<User, PropsToOmit>; //username; birthday

type PropsToPick = 'id' | 'age';  
type NewUser = Pick<User, PropsToPick>; // id; age;
```

### Exclude, Extract

Как omit и pick, но для union типов

```ts
type CarBrand = 'bmw' | 'lada' | 'toyota' | 'audi';  
  
type GermanyCar = Exclude<CarBrand, 'lada' | 'toyota'>;  
type NotGermanyCar = Extract<CarBrand, 'lada' | 'toyota'>;

```
