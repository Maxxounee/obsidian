## Отличия от JS:
в js есть типизация, но слабая и динамическая.

### Слабая типизация:

Можно работать с разными типами данных, неявно их преобразуя (type correction) (плюс и минус одновременно)

```js
console.log("10" - 2); // число
console.log("10" * "2"); // число
console.log("10" / 2); // число
console.log("10" + 2); // строка
```

```js
const arr = [5, '10', {}, []];
```

```js
console.log(100500 == '100500');
console.log(100500 === '100500');

console.log(null == undefined);
console.log(null === undefined);
```

### Динамическая

Тип определяется в рантайме, а не на этапе компиляции кода

```js
let variable = 5;
variable = '5';

variable = { user: 'Petr' }

```

```js
function fn(data) {
	if (data) {
		return 'string';
	} else {
		return 777;
	}
}
```

## Почему это проблема

В типизированных языках наличие типа является "самодокументацией".

Проблема в больших проектах:

* Много данных, нет четкого описания
* На этапе разработки кода проблемы с типами приходится держать в голове
* Усложняет дебаг и тестирование
* Усложняет анализ кода. Требуется бОльшая когнитивная нагрузка для анализа кода
* Отсутствие адекватного автокомплита в среде разработки (приятный бонус. Какие поля есть у объекта, например)
