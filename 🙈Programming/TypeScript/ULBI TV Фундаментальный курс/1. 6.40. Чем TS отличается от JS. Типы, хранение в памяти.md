
TS содержит все, что есть в JS, но и расширяет его.

В js есть типизация, но слабая:

7 примитивов:
* String
* Number
* BigInt
* Boolean
* Undefined
* Null
* Symbol

Объекты (ссылочные типы данных). Сюда входят:
* Object
* Fn
* Data
* Array
* и тд

Примитивы просто копируются. У ссылочных копируется ссылка (адрес) на память.

___

TS — язык со статической типизацией (явной или выводимой + структурной)

### Статическая 

Статическая типизация означает, что типы проверяются на этапе написания/компиляции кода, а не в рантайме (выполнения).

### Явная или выводимая 

Явная или выводимая типизация:

```ts
let variable: number = 5; // Явная
let variable = 5; // Выводимая. TS сам выводит number
```


### Структурная

Типы взаимозаменяемы

```ts
type User = {
	firstName: string;
	lastName: string;
}

type Person = {
	firstName: string;
	lastName: string;
}

// Эти два типа взаимозаменяемы. Если fn ожидает тип User, то она не будет
// ругаться, если передать Person. Многие языки не имеют структурной типизации
```
