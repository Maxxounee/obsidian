## Typeof
### JS 

Есть в js. <mark>Работает в runtime</mark>
```ts
typeof 777;
typeof 'str';
typeof true;
typeof {}
typeof [];
typeof null
typeof undefined
typeof function
typeof Symbol('str');
```

### TS

У TS есть свой оператор typeof, который позволяет извлекать типы.
Так же возвращает тип. Но это <mark>не runtime</mark> инструмент!

```ts

const obj = {
	name: '123',
	age: 25,
}

type Person = typeof obj;

const obj2: Person = {  
    name: '123',  
    age: 123,  
}
```

#### Строка

typeof присвоит литерал.

```ts
const color = 'red';  
type RedColor = typeof color; // Присвоит литерал 'red', а не тип string.  
  
const green: RedColor = 'green'; // Ошибка  
const red2: RedColor = 'red';
```

#### Функции

```ts
function getData(user: Person): number {  
    return 5;  
}  
  
type GetDataFn = typeof getData; // примет принимаемое и возвращаемое значения

type GetDataReturnVal = ReturnType<typeof getData> // примет number

type GetDataParams = Parameters<typeof getData> // примет Person

```


## Keyof

Позволяет доставать ключи из типов и интерфейсов

```ts
const obj = {  
    name: 'asd',  
    age: 25,  
}  
  
type Obj = typeof obj;  
  
type ObjKey = keyof Obj;

type ObjKey2 = keyof typeof obj;  
```

```ts
const obj = {  
    name: 'asd',  
    age: 25,  
}  
  
function getByKey<T, K extends keyof T>(obj: T, key: K): T[K] {  
    return obj[key];  
}  
  
console.log(  
    getByKey(obj, 'name')  
);
```
