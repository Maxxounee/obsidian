### const enum vs enum

Отличия в компиляции

#### enum

```ts
enum Color {
	RED = 'red',
	GREEN = 'green',
	BLUE = 'blue',
}

console.log(Color.RED);

// Скомпилируется в

"use strict";  
var Color;  
(function (Color) {  
    Color["RED"] = "red";  
    Color["BLUE"] = "blue";  
})(Color || (Color = {}));  
  
console.log(Color.RED);
```

#### const enum

```ts
const enum Color {
	RED = 'red',
	GREEN = 'green',
	BLUE = 'blue',
}

console.log(Color.RED);

// Скомпилируется в

"use strict";  
console.log("red" /* Color.RED */);
```

### Object

```ts
const COLOR = {  
    RED: 'red',  
    GREEN: 'green',  
    BLUE: 'blue',  
} as const;  

// Получаем [ключи объекта] и достаем из COLOR литералы red green blue
type Color = typeof COLOR[keyof typeof COLOR];  
  
const test: Color = 'red'; // ok
const test2: Color = 'asd'; // fail
```

И с помощью хелпера

```ts
const COLOR = {  
    RED: 'red',  
    GREEN: 'green',  
    BLUE: 'blue',  
} as const;  

type ValueOf<T> = T[keyof T];

type Color2 = ValueOf<typeof COLOR>;  
					  
const test2: Color2 = 'green';
```

## Сравнение Enum; ConstEnum; Const obj


| Характеристика           | Enum                    | Const Enum          | Const Objects            |
| ------------------------ | ----------------------- | ------------------- | ------------------------ |
| Доступность в runtime    | Да                      | Нет                 | Да                       |
| Размер бандла            | Больше                  | Меньше              | Меньше                   |
| Типизация                | Отличная                | Отличная            | Требует явного задания   |
| Двустороннее отображение | Да                      | Нет                 | Нет                      |
| Удобство                 | Удобно для перечислений | Удобно для констант | Простое и гибкое решение |
