По большей части разницы нет. Есть детали, которые отличаются

### 1. Литералы, примитивы

Чтобы описать литерал или примитив, нужно использовать type

```ts
type Literal = 'red' | 'green';
type Primitive = number;

type SomeAlias = number; // какой-нибудь алиас для id
```

### 2. Расширение

interface расширяется через extends, type через объединение. Разная семантика
```ts
interface Base {
	username: string;
	age: number;
}

interface User extends Base {
	password: string;
}

type User Base & {
	password: string;
}
```

### 3. Прикол.

interface объединятся в один по названию. С type будет ошибка

```ts
interface Base {
	username: string;
	age: number;
}

interface Base {
	password: string;
}

const user: Base = {// username age password }
```

### 4. Кортеж

Кортеж — массив определенной длины с заранее определенной структурой.

Можно определить только через type

```ts
type Tuple = [number, string, 5]

const tuple: Tuple = [3, '1', 6]
```

### 5. Функция

Через type удобно. Через interface тоже можно, но сложнее

```ts
type Fn = (arg: number) => void;

interface Fn2 {
	(arg: number) => void
}

const fn: Fn = (arg) => {}
const fn: Fn2 = (arg) => {}
```
