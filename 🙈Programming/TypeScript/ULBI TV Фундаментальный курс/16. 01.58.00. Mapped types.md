Mapped types — типы, которые позволяют создавать новые типы на основе существующих, изменяя какие-то поля

### Все поля в readonly

```ts
interface User {  
    name: string;  
    age: number;  
    friends: Array<string>;  
}  
  
type ReadonlyType<T> = {  
    readonly [K in keyof T]?: T[K]; 
    // в mapped type уже нельзя ничего больше добавить.

	// переопределить тип всех ключей на number:
    // [K in keyof T]: number;

	// сделать поля опциональными или nullable:
    // [K in keyof T]?: T[K] | null;
}  

// Отменить readonly и optional можно через минус
type EditableType<T> = {  
    -readonly [K in keyof T]-?: T[K];  
}  

type ReadonlyUser = ReadonlyType<User>;  
type EditableUser = EditableType<ReadonlyUser>;
```

### Исключить поле. Exclude

Хотим исключить из всех типов поле 'type'.

```ts
interface User {  
    name: string;  
    age: number;  
    friends: Array<string>;  
    type: string;  
}  
  
interface Car {  
    name: string;  
    type: string;  
}  
  
  
interface Book {  
    name: string;  
    type: string;  
}  
  
type WithoutType<T> = {  
    // Дословно: преобразуй тип K в тип, у которого исключен ключ 'type'  
    [K in keyof T as Exclude<K, 'type'>]: T[K];  
}  
  
type UserNoType = WithoutType<User>;  
type BookNoType = WithoutType<Book>;
```

### Переименовать ключи. Шаблонные строки

Так как ключами (keyof T) могут быть не только строки, то TS будет ругаться на попытку сделать `as get${K}`. 

1. Решаем это, например, типом Capitalize (отбросит всякие never) и слиянием типов string & K (приведет все, что возможно, к строке. Что невозможно — в never). 

2. Либо через Extract достаем только те ключи, которые соответствуют типу string.

```ts
interface Book {  
    name: string;  
    type: string;  
}  

type RenamedType<T> = {  
    [K in keyof T as `get${Capitalize<string & K>}`]: T[K];  
}  

type RenamedType2<T> = {  
    [K in Extract<keyof T, string> as `get_${K}`]: T[K];  
}  
  
type test = RenamedType<Book>;  // getName; getType
type test2 = RenamedType2<Book>; // get_name; get_type;
```
