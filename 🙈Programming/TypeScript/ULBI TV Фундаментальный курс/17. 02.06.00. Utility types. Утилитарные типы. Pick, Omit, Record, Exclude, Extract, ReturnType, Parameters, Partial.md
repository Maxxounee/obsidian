TypeScript Utility Types - это набор встроенных типов, которые можно использовать для манипулирования типами данных в коде.

### Awaited

Умеет рекурсивно разворачивать промисы и доставать то, что лежит внутри

```ts
type A = Awaited<Promise<string>>;
// type A = string

type B = Awaited<boolean | Promise<number>>;
// type B = number | boolean
```

### Partial

Mapped type. Делает все поля типа опциональными

```ts
interface Todo {  
    title: string;  
    desc: string;  
}  

// Если убрать Partial, то при вызове функции поле fields будет ожидать
// все значения (title и desc).
function update(todo: Todo, fields: Partial<Todo>) {  
    return {...todo, ...fields};  
}  
  
const todo1: Todo = {  
    title: '123',  
    desc: '312',  
}  
  
const todo2 = update(todo1, {desc: '123'});
```

### Required

Полная противоположность partial. Делает поля обязательными

```ts
interface Props {
	a?: number;
	b?: string;
}

const obj: Props = { a: 5 };

const obj2: Required<Props> = { a: 5 }; // fail. Property b is missing
```

### Readonly

Object.freeze

```ts
interface Todo {
	title: string;
}

const todo: Readonly<Todo> = {
	title: "Delete inactive users",
}

todo.title = 'Hello'; // fail. Cannot assign to 'title';
```

### Record<Keys, Type>

```ts
type CatName = "miffy" | "boris" | "mordred";

interface CatInfo {
	age: number;
	breed: string;
}

const cats: Record<CatName, CatInfo> = {
	miffy: { age: 10, breed: "Persian" },
	boris: { age: 5, breed: "Maine Coon" },
	mordred: { age: 16, breed: "British Shorthair" },
};

cats.boris;
```

```ts
type Color = 'red' | 'green' | 'blue' | 'yellow';  
  
type colorArray = Record<Color, string>;  
  
const colors:colorArray = {  
    red: 'str',  
    green: 'str',  
    blue: 'str',  
    yellow: 'str',  
}
```


### Pick<Type, Keys>

Создает тип из типа и ключей

```ts
interface User {  
    name: string;  
    age: number;  
    type: string;  
    friends: Array<string>;  
}  
  
type NewUser = Pick<User, "name" | "age">;  
```

### Omit<Type, Keys>

Создает тип. Убирает ключи из типа

```ts
interface User {  
    name: string;  
    age: number;  
    type: string;  
    friends: Array<string>;  
}  

type NewUser = Omit<User, "name" | "age">; 
```


### Exclude

Исключает. Работает как Omit, но с union type

```ts
type Color = 'red' | 'green' | 'blue' | 'yellow';  
  
type NarrowColor = Exclude<Color, 'blue' | 'yellow'>; // red green  
```

### Extract

Вытаскивает. Работает как Pick, но с union

```ts
type Color = 'red' | 'green' | 'blue' | 'yellow';  
  
type NarrowColor2 = Extract<Color, 'blue' | 'yellow'>; // blue yellow
```


### ReturnType, Parameters

Вытаскивает типы из функции

```ts
declare function f1(arg: { a: number, b: string }): void;

type T0 = Parameters<() => string>; // []
type T1 = Parameters<(s: string) => void>; // [s: string]
type T2 = Parameters<<T>(arg: T) => T>; // type T2 = [arg: unknown]
type T3 = Parameters<typeof f1>; // type T3 = [arg: { a: number; b: string; }]
type T4 = Parameters<any>; // type T4 = unknown[]
type T5 = Parameters<never>; // type T5 = never

type T6 = Parameters<string>;
// Type 'string' does not satisfy the constraint '(...args: any) => any'.
// type T6 = never

type T7 = Parameters<Function>;
// Type 'Function' does not satisfy the constraint '(...args: any) => any'. Type 'Function' provides no match for the signature '(...args: any): any'.
// type T7 = never
```

```ts
declare function f1(): { a: number; b: string };

type T4 = ReturnType<typeof f1>;
// type T4 = { a: number; b: string; }
```
