Ранее мы рассматривали type guards

type guard:

```ts
interface User {
	name: string;
	age: number;
}

function isUser(data: object): data is User {
	return 'name' in data && 'age' in data;
}
```

type assertion:

```ts
interface User {
	name: string;
	age: number;
}

const user = {
	name: 'Max',
}

function prepareUser(user: User) {
	//...
}

prepareUser(user as User)
```

## Asserts

Еще один вариант type guard.

### asserts condition

Не изменяет тип

```ts
function assertNotNull(value: unknown): asserts value {
	if (value === null || value === undefined) {
		throw new Error("Value is null or undefined");
	}
}
```

### asserts value is Type

TS подхватит тип, если пропустить переменную через функцию

```ts
interface User {  
    name: string;  
    age: number;  
}  
  
function assertIsUser(data: any): asserts data is User {  
	// В самой функции можно даже ничего не писать. TS подхватит тип
	// после выполнения функции и отсутствия ошибок.
    if (typeof data !== "object" || data === null) {  
        throw new Error('ojbecet');  
    }  
    if (typeof data.name !== "string") {  
        throw new Error("prop")  
    }  
    if (typeof data.age !== "number") {  
        throw new Error("num")  
    }  
}  
  
const test = {  
    name: 'asd',  
    age: 123,  
}  
  
console.log(test);  // Здесь еще нет типа

assertIsUser(test);  
  
console.log(test); // Тут TS присвоит тип USER переменной test (После прохождения assertIsUser)
```
