### Повторим условный тип

(Дословно: Расширяет ли T нужный нам тип?)

```ts
type IsString<T> = T extends string ? true : false;

type True = IsString<string>;
type True = IsString<number>;
```

### infer

Работает как дженерик, но внутри объявляемого типа. Можно назвать его динамическим типом

#### функции

Как достать returnType или parameters не используя их? Напишем аналоги

```ts
function fn(arg1: string): string {  
    return '';  
}  
  
// Если T расширяет функцию, то  
// если не расширяет, отдаем never (потому что не можем ничего вытащить из переданного значения)  
type MyParameters<T> = T extends (args: infer U) => any ? U : never;  
type MyReturnType<T> = T extends (...args) => infer U ? U : never;  
  
// arg: infer U — это как generic, но уже внутри объявляемого типа.  
  
type MyParams = MyParameters<typeof fn>;  
type MyReturn = MyReturnType<typeof fn>;  

// тут все ок
function test(arg: MyParams): MyReturn {  
    return '123';  
}  
  
// args не соответствуют. Return number тоже не соответствует
function test2(...args: MyParams): MyReturn {  
    return 123;  
}
```


#### Тип массива

```ts
type GetArrayItemType<T> = T extends (infer ItemType)[] ? ItemType : never;  
  
const array1 = [123, '123'];  
const array2: string[] = [];  
  
type ArrayItem1 = GetArrayItemType<typeof array1>;  // number | string
type ArrayItem2 = GetArrayItemType<typeof array2>; // string
```
