
```ts
type SuperType = {
	name: string;
}

type SubType = {
	name: string;
	age: number;
}

// так можно:
const subType: SubType = { name: 'asddas', age: 25 }
const superType: SuperType = subType; 

// Так ошибка:
const superType2: SuperType = { name: '12321' };
const subType2: SubType = superType2; // ошибка. Не хватает поля "age"
```

SubType содержит все те же поля, что и Supertype, но добавляет свои. Если проводить аналогию с ООП, то subType наследуется от superType. Реального наследования нет. Супертипу можно присвоить объект типа SubType — ошибки не будет.

## Резюме

Подтип (sub) включает все свойства и/или методы надтипа, плюс может добавлять свои.

Надтип (super) может содержать меньше свойств и/или методов, чем подтип.

Объект подтипа может быть присвоен переменной надтипа. Обратное не всегда возможно без приведения типов
