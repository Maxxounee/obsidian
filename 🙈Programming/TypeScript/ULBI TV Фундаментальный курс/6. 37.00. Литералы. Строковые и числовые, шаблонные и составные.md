### Литералов существует несколько видов:

* Строковые литералы(string) `"123" | "321"`
* Числовые литералы(number) `123 | 311`
* Булевы литералы(boolean) `false | true`
* Шаблонные строковые литералы (`example_${var}`)
* Составные литералы `= 123 | '123'`

## Строковые и числовые
#### Readonly в type

```ts
type Color = 'red' | 'green' | 'blue'; // Объявление через union
type Size = 4 | 8 | 16;

const color: Color = 'red';
const values = {
	color: 'green'
} as const; // Без const ts будет ругаться, потому что мы можем изменить color

function paint(color: Color) {}

paint(color);
paint(values.color);
```

#### Readonly в interface

```ts
interface User {
	readonly id: string;
}
```

## Шаблонные литералы

```ts
type EventName = 'click' | 'change';
type EventHandler = `on${EventName}`; // onclick | onchange

// Возможны подобные варианты:
type Userid = `user_id_${string}`;
type Userid = `user_id_${number}`;
type Userid = `user_id_${bigInt}`;
```
