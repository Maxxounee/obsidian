Дженерик — это как аргумент функции, только тип. Позволяет писать динамические типы внутри интерфейса. Может быть доступен внутри интерфейса, класса или функции. Делает возможным делать универсальные интерфейсы или функции.

```ts
interface MetaData {

}

interface User {
	username: string;
}

interface Article {
	title: string;
}

interface ApiResponse<T> { // Название можно взять любое. 
							// Классика — "T" (Type).
	status: 'error' | 'success';
	meta?: MetaData;
	requestId?: string;
	data: T;
}

const userResponse: ApiResponse<User> = { // Здесь, подобно аргументу, мы 
	// передаем тип в интерфейс, чтобы дать ему информацию. Если в 
	// интерфейсе указан generic, то при использовании интерфейса
	// обязательно нужно передать тип в виде аргумента
	
	data: { // data является типом User, потому что мы передали generic, 
	// а интерфейс использует его в data.
		username: 'Maks',
	}
}

const articleResponse: ApiResponse<Article> = { 
	data: {
		title: 'title',
	}
}
```

Типов (дженериков) может быть несколько:

```ts
interface ApiResponse<Data, Meta, Value> {
	status: 'error' | 'success';
	meta?: Meta;
	requestId?: string;
	data: Data;
	value: Value;
}

// Типы можно описать инлайново
const response: ApiResponse<User, {timestamp: string}, {number: number}> = {
	...
}
```

## Ограничения (Constraints)

Мы можем ограничить типы, которые дженерик будет использовать. То есть мы как бы загоняем объект (передаваемый аргумент) в определенные рамки.

```ts
interface User {  
    id: string;  
    created: Date;  
}  
interface Pizza {  
    id: string;  
    type: string;  
}  
  
const user: User = { id: '123', created: new Date() };  
const pizza: Pizza = { id: '123', type: 'peperonni' };  
  
// Функция будет ожидать тип, в котором определены id и created  
function createEntity<T extends {id: string, created: Date}>(arg: T) {  
    return null;  
}  
  
createEntity({ id: '123', created: new Date() }) // ok  
createEntity<User>(user); // ok  
createEntity<Pizza>(pizza); // fail. В Pizza не хватает created
createEntity<Pizza>({ ...pizza, created: new Date() }) // fail. 
```
