## 2. Что такое интерфейсы и абстрактные классы

Это два механизма для определения общего поведения для классов. Они похожи, но имеют важные различия.

**Абстрактный класс** — это класс, который нельзя создать напрямую (инстанцировать). Он служит базой для других классов.

**Интерфейс** — это контракт, который определяет, какие методы должны быть у класса, но не содержит их реализации.

## 3. Что такое инкремент и декремент. В чем разница между префиксной и постфиксной записями

**Инкремент** (`++`) — операция увеличения значения переменной на 1.  
**Декремент** (`--`) — операция уменьшения значения переменной на 1.

Эти операторы работают с числами, но также имеют особое поведение со строками и `null`.

### Префиксная и постфиксная формы

Каждая операция имеет две формы записи:

| Форма       | Запись         | Название                        |
| ----------- | -------------- | ------------------------------- |
| Префиксная  | `++$a`, `--$a` | Сначала изменить, потом вернуть |
| Постфиксная | `$a++`, `$a--` | Сначала вернуть, потом изменить |

#### Ключевое отличие

- **Префиксная** (`++$a`) — **сначала** увеличивает переменную, **потом** возвращает новое значение.  
- **Постфиксная** (`$a++`) — **сначала** возвращает текущее значение, **потом** увеличивает переменную.


## 4. Динамические переменные

**Динамические переменные** (или **переменные переменных**, variable variables) — это механизм PHP, позволяющий использовать значение одной переменной как **имя** другой переменной.

Обычная переменная: `$name`  
Динамическая переменная: `$$name` или `${$name}`

Двойной `$` означает: "возьми значение переменной `$name` и используй его как имя новой переменной".

## Простой пример

```php
$name = 'hello';
$$name = 'мир';
echo $hello;  // мир
echo $$name;  // мир (то же самое)
```

## 7. Какая система типов используется в PHP

PHP использует **номинальную систему типов** с **постепенной (gradual) типизацией**

Проще говоря, PHP — это **динамически типизированный язык** с возможностью **добавлять статические типы** там, где это нужно [](https://static.php.net/manual/it/language.types.intro.php)[](https://raw.githubusercontent.com/php/doc-en/117340b0d72bc8884290450ae8b89643528e0f58/language/types.xml#1).

- **Номинальная система (Nominal Type System)**: Совместимость типов определяется по **имени**типа (класса, интерфейса), а не по его структуре. Если класс `A` реализует интерфейс `B`, то объект `A` может быть использован там, где ожидается `B`.
- **Постепенная типизация (Gradual Typing)**: Вы можете писать код как полностью динамический (без указания типов), так и добавлять объявления типов для аргументов функций, возвращаемых значений и свойств классов [](https://raw.githubusercontent.com/xobotyi/cc-foundry/refs/heads/master/plugins/php/skills/php/references/typing.md#1).
## 8. Что такое магический метод

**Магические методы** — это специальные методы, которые начинаются с двойного подчёркивания (`__`) и вызываются автоматически PHP в определённых ситуациях, а не напрямую программистом.

Они позволяют классу реагировать на определённые "события": обращение к несуществующим свойствам, преобразование в строку, клонирование, сериализацию и т.д.

|`__destruct()`|При уничтожении объекта|
|`__call()`|При вызове недоступного метода|
|`__callStatic()`|При вызове недоступного статического метода|
|`__get()`|При чтении недоступного свойства|
|`__set()`|При записи в недоступное свойство|
|`__isset()`|При вызове `isset()`/`empty()` на недоступном свойстве|
|`__unset()`|При вызове `unset()` на недоступном свойстве|
|`__toString()`|При приведении объекта к строке|
|`__invoke()`|При вызове объекта как функции|
|`__clone()`|При клонировании объекта|
|`__sleep()`|При сериализации (`serialize()`)|

## 9. Что такое трейты

**Трейт** — это механизм **горизонтального повторного использования кода**. Он позволяет группе классов использовать один и тот же набор методов, не прибегая к наследованию.

```php
trait FullFeatured {
    // Свойства
    public $counter = 0;
    protected $name;
    private $secret;
    
    // Константы (PHP 8.2+)
    const VERSION = '1.0';
    
    // Обычные методы
    public function increment() {
        $this->counter++;
    }
    
    // Абстрактные методы (обязательны к реализации)
    abstract public function getName(): string;
    
    // Статические методы
    public static function create(): static {
        return new static();
    }
    
    // Магические методы
    public function __toString(): string {
        return static::class;
    }
}
```

```php
class MyClass {
    use A, B {
        A::hello insteadof B;  // Использовать hello из A, а не из B
        B::hello as helloB;  // Метод из B доступен как helloB
    }
    }
}

$obj = new MyClass();
echo $obj->hello();  // A
```

### Доступ к `$this`

Трейт "встраивается" в класс, поэтому внутри трейта доступны `$this` и всё, что есть в классе:

```php
trait Helper {
    public function describe() {
        // Обращение к свойству класса
        return "Я {$this->name}, класс " . static::class;
    }
}
class User {
    use Helper;
    
    public $name = 'Иван';
}
class Product {
    use Helper;
    
    public $name = 'Телефон';
}
echo (new User())->describe();     // Я Иван, класс User
echo (new Product())->describe();  // Я Телефон, класс Product
```

## 12. Разница между self и $this

|                     | $this                        | self                                         |
| ------------------- | ---------------------------- | -------------------------------------------- |
| Что это             | **Ссылка на текущий объект** | **Ссылка на текущий класс**                  |
| Тип                 | Переменная (объект)          | Ключевое слово (класс)                       |
| Доступ к чему       | Свойства, методы объекта     | Статические свойства, методы, константы      |
| Привязка            | К **экземпляру** (runtime)   | К **классу**, где написан код (compile-time) |
| Позднее связывание  | Всегда текущий объект        | Нет (см. `static`)                           |
| Можно использовать  | В обычных методах            | В любых методах                              |
| Нельзя использовать | В статических методах        | —                                            |
### $this — ссылка на объект

`$this` — это **псевдопеременная**, которая указывает на **текущий экземпляр** класса. Доступна **только в нестатических методах** (и в замыканиях, привязанных к объекту).

```php
class User {
    public $name = 'Иван';
    
    public function getName() {
        return $this->name;  // обращение к свойству объекта
    }
    
    public function greet() {
        return $this->getName();  // вызов метода объекта
    }
}
$user = new User();
echo $user->getName();  // Иван
```

### self — ссылка на класс

`self` — это **ключевое слово**, указывающее на **класс, в котором написан код**. Используется для доступа к статическим членам и константам.

Имеет доступ к const и статическим методам

```php
class User {
    const ROLE = 'user';
    public static $count = 0;
    
    public static function increment() {
        self::$count++;        // статическое свойство
        return self::ROLE;     // константа
    }
    
    public static function create() {
        return new self();     // создание объекта своего класса
    }
}
```
## 13. Что такое гератор

**Генератор** — это механизм, позволяющий создавать **итераторы без написания класса** и **вычислять значения по требованию** (лениво), вместо того чтобы хранить весь набор данных в памяти.

```php
function getNumbers(int $max): Generator {
    for ($i = 1; $i <= $max; $i++) {
        yield $i;  // отдаём по одному значению
    }
}

$numbers = getNumbers(1_000_000);
// ✅ В памяти: только текущее значение (~несколько байт)
foreach ($numbers as $n) {
    echo $n . "\n";
    if ($n >= 10) break;  // остановились — дальше не вычисляется
}
```
## 14. Что такое неймспейсы

**Пространство имён** — это способ **организовать код** и **избежать конфликтов имён** между классами, функциями и константами из разных частей программы или библиотек.

Проще говоря: namespace — это "папка" для имён. Как файловая система организует файлы, так namespace организует классы, функции и константы.

### Без namespace

```php
// File: User.php
class User {
    public function getName() { return 'User из моего кода'; }
}

// File: vendor/library/User.php
class User {  // ❌ Конфликт имён!
    public function getName() { return 'User из библиотеки'; }
}
```

При подключении обоих файлов PHP выдаст **фатальную ошибку**: `Cannot declare class User, because the name is already in use`.

### С namespace

```php
// File: MyApp/User.php
namespace MyApp;

class User {
    public function getName() { return 'User из моего кода'; }
}

// File: Vendor/Library/User.php
namespace Vendor\Library;

class User {
    public function getName() { return 'User из библиотеки'; }
}
```

Теперь это **разные классы**: `MyApp\User` и `Vendor\Library\User`. Конфликта нет.
## 15. Чем отличается include от require

Оба оператора **подключают и выполняют** указанный файл. Разница только в **поведении при ошибке**.

|                           | include                   | require                             |
| ------------------------- | ------------------------- | ----------------------------------- |
| При неудаче               | **Warning** (`E_WARNING`) | **Fatal Error** (`E_COMPILE_ERROR`) |
| Скрипт продолжает работу? | ✅ Да                      | ❌ Нет, останавливается              |
| Возвращает значение       | ✅ Да                      | ✅ Да                                |
| Когда использовать        | Необязательные файлы      | Критически важные файлы             |

### Наглядный пример

#### include — скрипт продолжается

```php
include 'nonexistent.php';
// Warning: include(nonexistent.php): Failed to open stream
echo "Этот код выполнится!";  // ✅ выполнится
```

#### require — скрипт останавливается

```php
require 'nonexistent.php';
// Fatal error: Failed opening required 'nonexistent.php'
echo "Этот код НЕ выполнится";  // ❌ не выполнится
```

### Варианты с _once

| Оператор       | Поведение                      |
| -------------- | ------------------------------ |
| `include`      | Подключает файл **каждый раз** |
| `include_once` | Подключает **только один раз** |
| `require`      | Подключает файл **каждый раз** |
| `require_once` | Подключает **только один раз** |


## 16. Как сделать, чтобы объект вел себя как массив

В PHP есть несколько способов сделать так, чтобы с объектом можно было работать как с массивом — через `[]`, `foreach`, `count()` и т.д. Выбор зависит от того, **насколько полную эмуляцию** массива вы хотите.

### Способы

| Способ                                | Что даёт           | Сложность |
| ------------------------------------- | ------------------ | --------- |
| `ArrayAccess`                         | Доступ через `[]`  | Низкая    |
| `Iterator` / `IteratorAggregate`      | `foreach`          | Низкая    |
| `Countable`                           | `count()`          | Низкая    |
| `ArrayObject` / `ArrayIterator` (Spl) | Всё сразу          | Низкая    |
| `__get`/`__set`                       | Частичная эмуляция | Средняя   |
#### 1. `ArrayAccess` — доступ через `[]`

Интерфейс `ArrayAccess` требует реализовать 4 метода:

```php
interface ArrayAccess {
    // isset($obj[$key])
    public function offsetExists(mixed $offset): bool;    
    
    // $obj[$key]
    public function offsetGet(mixed $offset): mixed;        
    
    //$obj[$key] = $value
    public function offsetSet(mixed $offset, mixed $value): void;  
    
    // unset($obj[$key]) 
    public function offsetUnset(mixed $offset): void;    
}
```

```php
class Collection implements ArrayAccess {
    private array $items = [];
    
    public function offsetExists(mixed $offset): bool {
        return isset($this->items[$offset]);
    }
    
    public function offsetGet(mixed $offset): mixed {
        return $this->items[$offset] ?? null;
    }
    
    public function offsetSet(mixed $offset, mixed $value): void {
        if ($offset === null) {
            $this->items[] = $value;   // $obj[] = $value
        } else {
            $this->items[$offset] = $value;
        }
    }
    
    public function offsetUnset(mixed $offset): void {
        unset($this->items[$offset]);
    }
}

$c = new Collection();
$c['name'] = 'Иван';       // offsetSet
$c['age'] = 25;
$c[] = 'доп';              // offsetSet с null

echo $c['name'];           // Иван (offsetGet)
var_dump(isset($c['age'])); // true (offsetExists)
unset($c['age']);          // offsetUnset
```

#### 2. Iterator — ручной обход для foreach

```php
interface Iterator extends Traversable {
    public function current(): mixed;     // текущий элемент
    public function key(): mixed;         // текущий ключ
    public function next(): void;         // вперёд
    public function rewind(): void;       // в начало
    public function valid(): bool;        // есть ли ещё
}
```

```php
class Collection implements Iterator {
    private array $items = [];
    private array $keys = [];
    private int $position = 0;
    
    public function __construct(array $items = []) {
        $this->items = array_values($items);
        $this->keys = array_keys($items);
    }
    
    public function current(): mixed { return $this->items[$this->position]; }
    public function key(): mixed { return $this->keys[$this->position]; }
    public function next(): void { $this->position++; }
    public function rewind(): void { $this->position = 0; }
    public function valid(): bool { return isset($this->items[$this->position]); }
}

$c = new Collection(['a' => 1, 'b' => 2, 'c' => 3]);
foreach ($c as $key => $value) {
    echo "$key => $value\n";
}
// a => 1, b => 2, c => 3
```

#### 3. IteratorAggregate — проще, чем Iterator

Вместо реализации всех 5 методов — вернуть готовый итератор:

```php
interface IteratorAggregate extends Traversable {
    public function getIterator(): Traversable;
}
```

```php
class Collection implements IteratorAggregate {
    private array $items = [];
    
    public function __construct(array $items = []) {
        $this->items = $items;
    }
    
    public function getIterator(): Traversable {
        return new ArrayIterator($this->items);
    }
}

$c = new Collection(['a' => 1, 'b' => 2]);
foreach ($c as $k => $v) {
    echo "$k => $v\n";
}
```


#### 4. Countable — для count()

```php
interface Countable {
    public function count(): int;
}
```

```php
class Collection implements Countable {
    private array $items = [];
    
    public function __construct(array $items = []) {
        $this->items = $items;
    }
    
    public function count(): int {
```

#### 5. Готовое решение: ArrayObject

```php
$obj = new ArrayObject(['name' => 'Иван']);

// Как массив
$obj['age'] = 25;
echo $obj['name'];       // Иван
unset($obj['name']);
var_dump(isset($obj['age'])); // true

// foreach
foreach ($obj as $k => $v) {
    echo "$k => $v\n";
}

// count
echo count($obj);

// Массив внутри
print_r($obj->getArrayCopy());

// Сортировка
$obj->asort();
```

##### Наследование от ArrayObject

```php
class Collection extends ArrayObject {
    public function __construct(array $items = []) {
        parent::__construct($items, ArrayObject::ARRAY_AS_PROPS);
    }
    
    public function add(mixed $value): static {
        $this->append($value);
        return $this;
    }
    
    public function first(): mixed {
        return $this->count() > 0 ? $this->getArrayCopy()[0] : null;
    }
}

$c = new Collection(['a', 'b']);
$c->add('c');
$c[] = 'd';
echo $c[0];       // a
echo $c->first(); // a
echo count($c);   // 4
```
## 17. Как при замыкании прокинуть переменную. 

В PHP замыкание **не видит** внешние переменные автоматически (в отличие от JavaScript). Их нужно явно передать через `use`.

### use
#### Без use 

```php
$name = 'Иван';

$fn = function() {
    echo $name;  // ❌ Warning: Undefined variable $name
};

$fn();
```

#### С use

```php
$name = 'Иван';

$fn = function() use ($name) {
    echo $name;  // ✅ Иван
};

$fn();
```


### По ссылке

По умолчанию переменная копируется **в момент создания** замыкания. Если нужно, чтобы замыкание видело **изменения** переменной — передавайте по ссылке:

```php
$count = 0;

$fn = function() use (&$count) {
    $count++;
};

$fn();
$fn();
echo $count;  // 2 — изменения видны снаружи
```

### Стрелочные функции (PHP 7.4+) — автоматический захват

Стрелочные функции **автоматически** захватывают переменные из внешней области **по значению**. `use` не нужен.

```php
$name = 'Иван';

$fn = fn() => $name;  // автоматически захватывает $name
echo $fn();  // Иван
```

Стрелочные функции захватывают **только по значению** — по ссылке нельзя.

```php
$count = 0;
$fn = fn() => $count++;  // ⚠️ не изменит внешний $count
$fn();
echo $count;  // 0 (изменения не выходят наружу)
```

## 19. Что будет с объектом после передачи в метод и его модификации. А если передать массив?

|Тип|Что передаётся|Изменения видны снаружи?|
|---|---|---|
|**Объект**|Копия **ссылки** на объект (handle)|✅ Да (при изменении свойств)|
|**Массив**|**Копия** значения (copy-on-write)|❌ Нет (без `&`)|
|**Скаляр** (int, string, bool)|**Копия** значения|❌ Нет (без `&`)|
|**Массив по ссылке** `&$arr`|**Ссылка** на массив|✅ Да|
|**Объект по ссылке** `&$obj`|**Ссылка** на переменную|✅ Да|
