## Инкапсуляция (сокрытие)

Любой класс должен рассматриваться как "черный ящик", предоставляя пользователю только интерфейс взаимодействия. Способ защиты данных в объекте; Взаимодействие с состоянием только внутри этого объекта; Не позволять работать с данными извне.

Прячем внутренние данные класса и даем доступ только через открытые методы.

## Наследование (расширение)

Возможность порождать один класс от другого с сохранением свойств и методов класса-предка, добавляя новые свойства и методы (расширять).

Повторное использование кода. Новый класс берет поля и методы родительского класса (существующего)

## Полиморфизм (переопределение поведения)

Возможность использовать классы-потомки в контексте, который был предназначен для класса-предка.

С объектами работаем через общий интерфейс. Поведение зависит от конкретного типа
